# שחר חוויות חינוכיות — אתר חדש

אתר סטטי (HTML/CSS/JS ללא תלות בבנייה) עבור שחר חוויות חינוכיות בע"מ (לשעבר מעשיותיאטרון).

## מבנה
- `index.html` — דף הבית
- `about.html` — מי אנחנו
- `classes.html` — חוגים שנתיים
- `events.html` — הפעלות לאירועים
- `shows.html` — הצגות
- `testimonials.html` — המלצות
- `contact.html` — צור קשר
- `css/style.css` — עיצוב
- `js/main.js` — תפריט נייד, טופס יצירת קשר, אנימציות גלילה
- `images/activities/` — תמונות פעילות

## הרצה מקומית
כל דפדפן יכול לפתוח את `index.html` ישירות, או להריץ שרת מקומי:
```
python3 -m http.server 8000
```

## פריסה
אתר סטטי טהור — מתאים לפריסה ב-Render (Static Site), Vercel, Netlify או GitHub Pages ללא כל תצורת build.
